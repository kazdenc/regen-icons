# Community conduct

We want this project to be a welcoming place to share ideas, report problems, and
review work. Be respectful, assume good intent, and give feedback about the work rather
than the person. Harassment, discrimination, threats, and personal attacks are not
welcome.

If you experience or witness unacceptable behaviour, report it privately through the
repository's GitHub private reporting channel. Maintainers will review reports promptly
and may remove content, limit participation, or take other action needed to protect the
community.

Project maintainers should enable private reporting before the repository is announced.
